# Kaizen resolve compatibility redirect

Problem retirement now belongs to [problem-resolve](../problem-resolve/SKILL.md).
For an invocation naming a problem, disclose the redirect, read that skill,
and pass through the original argument and authorization. Do not run the old
journal deletion cascade. For journal or pattern work, use
[kaizen-review](../kaizen-review/SKILL.md) within the user's requested scope.

This redirect carries no independent procedure. Keep it while older consumers
and invocations still name it; new guidance must name the owning skill.
